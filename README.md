# Food Transparency Coalition website

A plain static site (no build step). Vercel serves these files as-is.

| File | What it is |
| --- | --- |
| `index.html` | The whole page |
| `config.js` | **Petition links.** Paste the Regulations.gov links here once the FDA assigns a docket number |
| `assets/` | Background texture and the social share image |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Browser tab and phone home-screen icons |

To update the site: edit a file on GitHub (pencil icon → "Commit changes"). Vercel redeploys automatically in about 30 seconds.

Design source: Tyler's Claude Design file ("Food Transparency Coalition.dc.html").
